# Test technique — AI Engineer senior

**Durée : 90 minutes. Livrable : dépôt GitHub accessible à l’évaluateur.**

Ce dépôt contient l’énoncé, les données et les documents métier nécessaires au test.
La réalisation technique est entièrement à votre charge.

**Règle du test : Copilot et tout autre assistant de code/assistant IA d’aide à la réalisation sont
interdits. Les recherches Internet, la documentation et les téléchargements restent autorisés.**
Le modèle local nécessaire à l’analyse des données du sujet reste obligatoire.

## Commencer

```bash
git clone --depth 1 https://github.com/kwemard/test_IA_Engineer_Senior.git
cd test_IA_Engineer_Senior
```

Vérifiez les prérequis dans [PREPARATION.md](PREPARATION.md), puis lisez
[INSTRUCTIONS_CANDIDAT.md](INSTRUCTIONS_CANDIDAT.md).
La description des données est dans [DESCRIPTION_DONNEES.md](DESCRIPTION_DONNEES.md) ;
le résultat attendu est défini dans [FORMAT_RAPPORT.md](FORMAT_RAPPORT.md).

Toutes les données disponibles figurent dans `data/` et `documents/`.
Elles sont fictives. Aucun fichier audio ni accès à un système externe n’est nécessaire.

Au début du test, créez votre réalisation à partir de ce contenu. À la fin, remettez l’URL de votre
propre dépôt, le SHA final et le lien vers l’exécution GitHub Actions. Le dépôt de référence partagé
sert uniquement à distribuer le sujet.
